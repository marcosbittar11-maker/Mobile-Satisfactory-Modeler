# Factory Flow PWA — v0.4.9
Aplicativo web instalável no iPhone, derivado da versão v0.4.9 do Modeler offline.
Para publicar, ative GitHub Pages: Settings > Pages > Deploy from a branch > gh-pages > /(root) > Save.
A instalação é feita no Safari: Compartilhar > Adicionar à Tela de Início > Abrir como App.
Abra a primeira vez online para guardar os arquivos; depois funciona offline.
Os projetos antigos salvos no Edge devem ser exportados como JSON e importados no PWA.
O armazenamento local do PWA é independente, e backups JSON continuam recomendados.
Projeto não oficial relacionado ao jogo Satisfactory; ativos do jogo pertencem aos respectivos titulares.
